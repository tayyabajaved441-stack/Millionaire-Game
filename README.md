# Millionaire Game - Who Wants to Be a Millionaire? 💰

A Python-based console quiz game inspired by "Kaun Banega Crorepati" (KBC). Answer MCQs correctly and win virtual prize money!

### 🎯 Features
- **11 Levels of Questions:** Difficulty increases with prize money
- **Cash Prize System:** Win money on every correct answer
- **Safe Levels:** Two safe points (like KBC) - you won't go below them
- **Lifelines:** 50-50, Audience Poll, Phone a Friend (coming soon)
- **Interactive UI:** Clean and fun console experience
